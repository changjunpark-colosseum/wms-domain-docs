# 용어 사전

<div class="page-meta"><span>부록</span><span>용어</span><span>찾아보기</span></div>

시스템마다 같은 개념을 다른 이름으로 부를 수 있습니다. 용어보다 정의와 상태 경계를 먼저 확인하세요.

## A–L

| 용어 | 정의 |
|---|---|
| Allocation | Available 재고를 주문에 예약하는 장부 행위 |
| ASN | 공급자가 보내는 입고 예정 정보, Advance Shipping Notice |
| Available | 새 주문에 약속할 수 있는 자유 재고 |
| Dock | 차량이 접안해 입하·상차하는 창고 접점 |
| FEFO | 유효기간이 먼저 끝나는 재고부터 선택하는 방식 |
| FIFO | 먼저 입고된 재고부터 선택하는 방식 |
| Inventory | SKU별 장부 총량 또는 집계 관점의 재고 |
| Location | 재고를 식별해 놓는 구체적인 창고 주소 |
| LOT | 같은 생산·입고 특성을 공유하는 재고 묶음 속성 |
| LPN | 취급 단위의 재고 묶음과 수량 계보를 식별하는 번호 |

## M–S

| 용어 | 정의 |
|---|---|
| OMS | 주문 수집·분배·상태를 관리하는 Order Management System |
| Packing | 피킹 결과를 주문과 대사해 박스 단위로 포장하는 작업 |
| Picking | 할당된 재고를 Location에서 꺼내는 물리 작업 |
| Product | 판매 관점에서 여러 SKU를 묶는 상품 정의 |
| Putaway | 입고확정 재고를 보관 Location에 적치하는 작업 |
| Replenishment | PICK Location의 작업 가능 수량을 회복하는 보충 작업 |
| SKU | 재고로 구분해 취급하는 최소 상품 단위, Stock Keeping Unit |
| SOH | 창고가 물리적으로 보유한 총량, Stock on Hand |
| Stock | Location·LPN·상태별 실물 상세 재고 |

## T–Z

| 용어 | 정의 |
|---|---|
| UOM | EA·BOX·PLT처럼 수량을 표현하는 단위, Unit of Measure |
| Wave | 비슷한 주문을 실행 단위로 묶는 출고 계획 |
| WIP | 피킹·패킹·이동·반환 등 작업 중인 재고 |
| WMS | 창고 안의 재고, 위치와 작업을 관리하는 시스템 |
| Zone | 비슷한 공정·품질·보관 정책을 가진 공간 묶음 |

## 한국어 용어

| 용어 | 정의 |
|---|---|
| 가용재고 | 새 주문에 사용할 수 있는 Available 재고 |
| 검수 | 예정 정보와 실제 상품·수량·품질을 비교하는 작업 |
| 수불 이력 | 입고·출고·조정 등 재고 증감 원인을 기록한 장부 |
| 실사 | 시스템 장부와 물리 수량을 실제로 세어 비교하는 작업 |
| 양품화 | 반품·보류 재고를 정상 판매 가능한 상태로 회복하는 과정 |
| 입하 | 차량·팔레트·박스가 창고에 물리적으로 도착했음을 등록하는 단계 |
| 출고확정 | 상차·인계를 완료하고 재고를 SOH에서 이탈시키는 사건 |
| 폐기 | 승인된 사유와 증빙으로 재고를 실제 처분하는 작업 |
