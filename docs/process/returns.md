# 반품 프로세스

<div class="page-meta"><span>반품</span><span>역물류</span><span>11분</span></div>

반품은 **출고된 상품이 돌아왔을 때 원출고와 연결하고 품질을 다시 판정해 재고화 또는 비재고 경로로 종결하는 과정**입니다.

## 표준 흐름

<div class="flow-strip"><span>원출고·송장 조회</span><i>→</i><span>반품 접수</span><i>→</i><span>회수·반입</span><i>→</i><span>상품·수량 검수</span><i>→</i><span>품질 판정</span><i>→</i><span>재입고·폐기·반송</span></div>

## 왜 일반 입고와 다를까?

반품 상품은 이미 고객에게 전달됐거나 운송 과정을 거쳤기 때문에 정상 판매 자격을 다시 확인해야 합니다. 도착했다고 바로 Available로 만들면 사용 흔적·파손·오염이 있는 상품이 정상 주문에 할당될 수 있습니다.

## 품질 경로

| 판정 | 후속 처리 | 재고 의미 |
|---|---|---|
| 정상 | 재포장·보관 Location 적치 | 재입고 완료 후 Available 후보 |
| 보류 | 추가 검사·승인 | HOLD, Unavailable |
| 리퍼비시 | 수선·재가공 | 별도 WIP |
| 불량 | 격리·공급처 반송 | Unavailable |
| 폐기 | 승인·증빙·실제 처분 | SOH 감소 또는 재고화 없이 종결 |

## 재고 반영 경계

1. **반입:** 실물이 반품 Zone에 도착했지만 정상 Inventory 증가와는 분리합니다.
2. **검수:** 원출고 SKU·수량과 실물을 대사합니다.
3. **품질 판정:** 정상·보류·불량 경로를 결정합니다.
4. **재입고:** 정상 판정 수량만 명시적인 재입고 사건으로 편입합니다.

## 주요 정책

- 원출고·송장·주문 라인과 반품 수량을 연결합니다.
- 부분·중복 반품의 누적 허용 수량을 검증합니다.
- 품질 판정 전 재고는 정상 재고와 격리합니다.
- 모든 반품 라인이 하나의 종결 경로를 가져야 전체 완료됩니다.
- 외부 환불·재고 동기화 재시도가 중복 재입고를 만들지 않습니다.

## 예외 상황

- 송장이나 원출고를 찾을 수 없는 무자료 반품
- 주문 수량보다 많은 반품
- 다른 SKU가 들어온 오반품
- 패키지 구성품 일부 누락
- 품질 판정 변경과 재검수
- 환불은 성공했지만 재고 동기화가 실패한 경우

## 확인 문제

1. 반품 Zone 도착과 재입고를 같은 사건으로 처리하면 어떤 위험이 있을까요?
2. 부분 반품을 여러 번 허용할 때 어떤 누적 수량을 보존해야 할까요?
3. 폐기 대상 반품을 SOH에 먼저 넣었다가 빼는 방식과 처음부터 격리하는 방식의 차이는 무엇일까요?
