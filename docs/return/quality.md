# 품질 판정

<div class="page-meta"><span>반품</span><span>양품·보류·불량</span><span>9분</span></div>

품질 판정은 검수된 반품 상품이 정상 판매 재고로 돌아갈 수 있는지 결정하는 단계다.

## 판정 결과

| 판정 | 설명 | 후속 경로 |
|---|---|---|
| 양품 | 정상 판매가 가능함 | 양품화·재입고 |
| 보류 | 추가 확인·승인·수리가 필요함 | HOLD·재검수 |
| 불량 | 정상 판매가 불가능함 | DEFECT·폐기·반송 |

## 품질 판정 흐름

<div class="flow-strip"><span>검수 수량 확인</span><i>→</i><span>외관·기능·구성 판정</span><i>→</i><span>양품·보류·불량 수량 입력</span><i>→</i><span>사유·증빙 등록</span><i>→</i><span>수량 합 검증</span><i>→</i><span>후속 작업 생성</span></div>

## 수량 관계

```text
양품 수량 + 보류 수량 + 불량 수량 = 검수 수량
```

## 정책

1. 판정 전 상품은 HOLD·가용불가 상태를 유지한다.
2. 양품·보류·불량 수량 합은 검수 수량과 일치해야 한다.
3. 같은 수량을 양품화와 폐기 양쪽에 중복 배정하지 않는다.
4. 판정 사유, 증빙, 판정자와 시각을 기록한다.
5. 품질 판정을 변경할 때 기존 결과를 삭제하지 않고 재판정 이력을 남긴다.
6. 보류 상품은 승인 없이 양품·불량으로 종결하지 않는다.
7. Container별 상품·수량과 품질 결과를 연결한다.

## 예외

- 판정 수량 합 불일치
- 최종 판정 권한 없음
- 증빙 없이 불량·폐기 판정
- 품질 판정 전 가용재고 반영
- 빈 Cart·Container 작업 완료
- 재판정 과정에서 기존 수량 중복 처리
