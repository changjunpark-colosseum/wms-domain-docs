# 반품 신청·원출고 조회

<div class="page-meta"><span>반품</span><span>원출고 연결</span><span>9분</span></div>

반품 신청은 임의 상품을 입고하는 것이 아니라 실제 출고된 상품을 원출고·송장과 연결해 되돌리는 작업의 시작이다.

## 조회 식별자

- 원송장번호
- 출고번호
- 판매번호
- 패킹 슬립
- 반품번호

## 신청 흐름

<div class="flow-strip"><span>원송장·출고 조회</span><i>→</i><span>출고 상품·수량 확인</span><i>→</i><span>반품 상품·수량 선택</span><i>→</i><span>반품 유형·사유 입력</span><i>→</i><span>단건·엑셀 등록</span><i>→</i><span>반품번호 확인</span></div>

## 반품 가능 수량

```text
반품 가능 수량
= 원출고 수량 - 기존 반품 수량 - 이미 취소·회수된 수량
```

## 정책

1. 출고 완료된 원출고와 유효한 송장을 기준으로 반품 대상을 찾는다.
2. 반품 상품·UOM·수량을 원출고 상품 라인과 연결한다.
3. 누적 반품 수량이 원출고 수량을 초과하지 않게 한다.
4. 단건·엑셀 등록에 같은 상품·수량·중복 검증을 적용한다.
5. 반품번호, 원출고, 원송장, 등록자와 사유를 연결한다.
6. 같은 원송장·상품·수량으로 반품이 중복 생성되지 않게 한다.
7. 원출고가 없는 상품은 일반 반품과 분리해 관리자 확인 대상으로 처리한다.

## 반품 유형

| 유형 | 설명 |
|---|---|
| 일반 반품 | 배송된 상품을 고객·화주가 반환 |
| RTS | 수취인 미도착·배송 실패 등으로 배송사가 반송 |

## 예외

- 출고 완료 전 상품 반품 신청
- 원송장과 출고 주문 불일치
- 원출고 수량보다 큰 반품 수량
- 같은 상품의 중복 반품
- 엑셀 파일 일부 행 오류
- 원출고를 찾을 수 없는 무자료 반품
