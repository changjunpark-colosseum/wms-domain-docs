# 불량·폐기·반송

<div class="page-meta"><span>반품</span><span>불량 종결</span><span>9분</span></div>

불량 반품은 정상 재고로 복귀시키지 않고 DEFECT·폐기 Zone에 격리한 뒤 폐기·공급처 반송 등으로 종결한다.

폐기 Zone 이동은 `화주사 확인을 요청하지 않았기 때문`에 발생하지 않는다. 작업 등록에서 불량 수량으로 분류된 상품이 검수를 통과했을 때 폐기 Zone 스캔 단계로 이동한다. 화주사 확인을 요청한 건은 승인 전까지 이 경로를 시작하지 않는다.

## 처리 흐름

<div class="flow-strip"><span>불량 수량·사유 확인</span><i>→</i><span>DEFECT·폐기 Zone 이동</span><i>→</i><span>승인·증빙 등록</span><i>→</i><span>실제 폐기 또는 반송</span><i>→</i><span>상품 상태 완료</span></div>

## 정책

1. 불량·폐기 수량을 양품 Inventory에 포함하지 않는다.
2. RETURN Zone에서 DEFECT Zone으로 이동할 때 상품·수량을 보존한다.
3. 폐기 Zone 이동과 실제 폐기를 별도 사건으로 기록한다.
4. 폐기 사유, 승인자, 실행자, 시각과 증빙을 보존한다.
5. 승인 전 실제 폐기를 완료하지 않는다.
6. 일부 양품·일부 불량이면 수량 합을 검수 수량과 맞춘다.
7. 공급처 반송은 반송 대상·수량·송장 등 별도 이력을 남긴다.
8. 이미 양품화된 Stock을 폐기할 때만 별도 재고 감소 사건을 적용한다.
9. 화주사 확인 요청 상태인 상품은 APRV 승인 전 폐기 Zone으로 이동하지 않는다.

## 상태

| 상태 | 설명 |
|---|---|
| 불량 대기 | BAD 판정·RETURN Zone |
| 폐기·반송 진행 | DEFECT Zone·승인·실물 처리 중 |
| 완료 | 폐기·반송과 증빙 저장 완료 |

## 예외

- 승인·증빙 없는 폐기
- 양품화되지 않은 반품의 Inventory 중복 감소
- 폐기 수량과 실제 수량 불일치
- 폐기 완료 뒤 수량 수정
- 공급처 반송 송장·수량 누락
