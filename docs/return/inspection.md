# 반품 검수

<div class="page-meta"><span>반품</span><span>상품·수량 확인</span><span>9분</span></div>

반품 검수는 돌아온 실물이 원출고 상품과 일치하는지 확인하고 품질 판정에 사용할 상품·수량을 확정하는 작업이다.


## 검수 항목

- 원출고 SKU·바코드
- 반품 신청 수량과 실제 수량
- 상품 구성품·부속품
- LOT·유효기간·시리얼
- 포장·외관·파손·오염
- 사용 흔적과 재판매 가능 여부

## 검수 흐름

<div class="flow-strip"><span>Cart·Container 선택</span><i>→</i><span>상품·바코드 확인</span><i>→</i><span>수량 확인</span><i>→</i><span>구성·LOT·외관 확인</span><i>→</i><span>검수 결과 저장</span><i>→</i><span>품질 판정</span></div>

## 수량 관계

```text
검수 수량 = 반입 수량
품질 판정 수량 합 = 검수 수량
```

## 정책

1. 검수 상품을 원출고 상품 라인과 연결한다.
2. 신청 수량과 실제 반입 수량 차이를 별도로 기록한다.
3. LOT·유효기간·시리얼 관리 상품은 원출고·실물값을 비교한다.
4. 구성품 일부 누락과 다른 상품 혼입을 정상 검수로 처리하지 않는다.
5. 검수 전 상품은 HOLD 상태를 유지한다.
6. 검수 수량을 초과해 품질 판정하지 않는다.
7. 검수 결과, 사진·증빙, 작업자와 시각을 보존한다.

## 예외

- 원출고와 다른 SKU
- 반품 신청보다 많은·적은 수량
- 구성품·부속품 누락
- LOT·유효기간·시리얼 불일치
- 상품 파손·오염
- Container 수량과 실물 수량 불일치
