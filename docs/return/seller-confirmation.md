# 화주사 확인

<div class="page-meta"><span>반품</span><span>승인</span><span>7분</span></div>

화주사 확인은 센터가 등록한 반품 수량·클레임 확정 사유·관리자 사유와 사진을 화주사가 검토한 뒤 센터의 후속 작업을 승인하는 선택 절차다.

모든 반품이 화주사 확인을 거치는 것은 아니다. 센터가 확인을 요청한 반품만 `REQR`에서 대기한다.

## 확인 요청 흐름

<div class="flow-strip"><span>센터 작업 등록</span><i>→</i><span>확인 요청 선택</span><i>→</i><span>REQR</span><i>→</i><span>화주사 상세 조회</span><i>→</i><span>화주사 메모·확인</span><i>→</i><span>APRV</span><i>→</i><span>센터 작업 재개</span></div>

## 확인하는 정보

- 반품번호·원출고·원송장
- 반품 상품·UOM·LOT·유효기간
- 정상 수량과 불량 수량
- 전체·SKU별 클레임 확정 사유
- SKU별 관리자 사유
- 센터 코멘트
- 상품 상태 사진

화주사는 상세 화면에서 센터가 남긴 코멘트와 사진을 확인하고 화주사 메모를 저장한다. 반품이 `REQR`이면 저장과 함께 승인 API가 실행된다.

## 확인 요청 여부에 따른 분기

| 확인 요청 | 상태 | 센터 후속 작업 |
|---|---|---|
| 요청하지 않음 | WAIT | 바로 시작 가능 |
| 요청함·미승인 | REQR | 시작 불가, 화주사 확인 대기 |
| 요청함·승인 완료 | APRV | 승인 목록·라벨 스캔 후 시작 가능 |

## 승인 뒤 상품 경로

화주사 승인은 상품의 양품·폐기를 새로 판정하는 동작이 아니다. 센터가 등록한 정상·불량 수량에 대한 후속 작업을 열어 주는 게이트다.

```text
APRV 상품 스캔·수량 검수
├─ 정상 수량 존재 → Cart·Container → 양품화
└─ 불량 수량 존재 → 폐기 Zone 스캔 → 불량·폐기
```

확인을 요청하지 않은 `WAIT` 상품도 같은 수량 기준으로 분기한다. 따라서 폐기 Zone 이동 여부는 화주사 확인 유무가 아니라 `불량 수량`으로 결정된다.

## 정책

1. 확인 요청 여부를 반품 저장 시 명시한다.
2. 확인 요청 반품은 화주사 승인 전 수량 검수·양품화·폐기 작업을 시작하지 않는다.
3. 화주사는 반품 상세의 상품·수량·사유·센터 코멘트·사진을 확인할 수 있어야 한다.
4. 승인 시 화주사 메모를 먼저 저장하고 반품 승인 상태를 함께 반영한다.
5. 승인된 상품은 `APRV` 목록과 반품 라벨 스캔으로 센터 작업에 다시 진입한다.
6. 승인을 폐기 판정으로 해석하지 않는다. 정상·불량 수량에 따라 후속 경로를 결정한다.
7. 확인을 요청하지 않은 반품은 `WAIT`에서 바로 작업할 수 있지만 동일한 수량·사유 검증을 적용한다.
8. REQR 상태가 유지되는 동안 상품을 자동 폐기하거나 가용재고로 전환하지 않는다.

## 예외

- 화주사 확인 전 센터 작업 시작
- 승인됐지만 APRV 상품이 승인 목록에 나타나지 않음
- 화주사 메모 저장 성공 후 승인 실패
- 원출고·수량·사진이 불충분한 상태에서 승인
- REQR 상품이 자동으로 폐기 Zone에 이동함
- 정상 수량을 폐기 경로로 보내거나 불량 수량을 양품화함
