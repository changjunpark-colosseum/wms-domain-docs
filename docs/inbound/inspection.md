# 검수

<div class="page-meta"><span>입고</span><span>상품·수량 확인</span><span>10분</span></div>

검수는 신청한 SKU와 실제 도착한 상품을 비교하고 재고로 반영할 상품·수량·LOT·유효기간을 확정하는 작업이다.

## 검수 흐름

<div class="flow-strip"><span>RO 입력</span><i>→</i><span>상품·바코드 확인</span><i>→</i><span>수량 입력</span><i>→</i><span>체적·이미지 확인</span><i>→</i><span>LOT·유효기간 입력</span><i>→</i><span>정상 또는 예외 처리</span></div>

## 검수 단위

```text
SKU × LOT × 유효기간 × 수량
```

같은 SKU라도 LOT나 유효기간이 다르면 별도 검수 행으로 처리한다.

## 수량 관계

```text
검수 대상 = 신청 수량 - 예외 확정 수량
검수 잔여 = 검수 대상 - 누적 정상 수량 - 예외 대기 수량
```

## 정책

1. 신청 상품·수량은 검수 결과로 덮어쓰지 않는다.
2. 실제 차이는 정상 검수 수량과 예외 수량으로 기록한다.
3. 여러 작업자가 동시에 검수할 때 남은 수량을 제출 시점에 다시 확인한다.
4. LOT·유효기간 관리 상품은 값을 필수로 입력한다.
5. 같은 LOT·유효기간 조합을 중복 입력하지 않는다.
6. 체적·이미지 등 상품 취급정보는 상품 기준정보와 연결한다.
7. 정상 검수 수량만 적치 대상으로 전달한다.
8. 검수 완료는 전체 상품 수량과 예외가 종결된 뒤 확정한다.

## 예외

- 신청에 없는 상품
- 바코드·SKU 불일치
- 초과·부족 수량
- 파손·오염·불량
- LOT·유효기간 불일치
- 필수 이미지·체적 정보 누락
- 동시에 같은 잔여 수량을 처리함
