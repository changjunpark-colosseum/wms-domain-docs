# 검수

<div class="page-meta"><span>입고</span><span>실물 확정</span><span>10분</span></div>

검수는 입고 주문과 실제 상품을 비교해 재고로 편입할 SKU·수량·LOT·유효기간과 품질 상태를 확정하는 공정이다.

## 검수 흐름

<div class="flow-strip"><span>작업 상품 선택</span><i>→</i><span>상품 식별</span><i>→</i><span>수량 확인</span><i>→</i><span>LOT·유효기간</span><i>→</i><span>상태·상세 검수</span><i>→</i><span>정상·예외 분리</span></div>

## 검수 항목

| 항목 | 확인 내용 | 소유 도메인 |
|---|---|---|
| 상품 식별 | SKU·바코드·UOM | 상품 |
| 물류 정보 | 체적·중량·취급 이미지 | 상품 |
| 수량 | 예정·실제·누적·잔여 | 입고 |
| 재고 속성 | LOT·유효기간·시리얼 | 재고 |
| 품질 | 정상·파손·오염·불일치 | 입고 예외 |

검수 화면에서 상품 정보가 부족하면 UOM·체적·중량·이미지를 보완할 수 있다. 하지만 해당 정보의 소유자는 상품 도메인이며 입고 작업마다 새 값을 만드는 것은 아니다.

## 수량

```text
검수 가능 수량
= 주문 예정 수량 - 누적 정상 수량 - 예외 점유 수량 - 종결 수량
```

여러 작업자가 처리할 수 있으므로 화면 진입 시점뿐 아니라 제출 시점에도 잔여 수량을 다시 검증한다.

## LOT·유효기간

| LOT 관리 | 유효기간 관리 | 입력 |
|---:|---:|---|
| Y | Y | LOT·유효기간별 수량 |
| Y | N | LOT별 수량 |
| N | Y | 유효기간별 수량 |
| N | N | 수량만 확정 |

세부 행의 수량 합은 검수 수량과 일치해야 한다. 같은 SKU라도 LOT·유효기간·입고회차가 다르면 별도 SKU Instance가 된다.

## 상세 검수

품질 지시가 있는 상품은 작업 설명과 참고 사진을 기준으로 실물을 비교한다. 이상 판정에는 사유와 수량을 기록하고 정상 수량과 분리한다.

## Pallet·취급 단위

검수 과정에서 Pallet·재포장 등 작업 유형과 부자재·횟수를 기록할 수 있다. 이는 작업 이력이며 Inventory 수량을 증가시키는 사건은 아니다.

## 검수 결과

```text
검수 결과
├─ 정상 수량 → 입고 작업·적치 대상
└─ 예외 수량 → 입고 예외 판정
```

## 정책

1. 입고 주문 상품과 실제 SKU를 연결한다.
2. 예정 수량과 실제 수량을 별도로 보존한다.
3. LOT·유효기간 관리 상품은 해당 값을 필수로 확정한다.
4. 세부 재고 속성별 수량 합을 검수 수량과 맞춘다.
5. 신청에 없는 상품과 수량 초과를 자동 정상 처리하지 않는다.
6. 상품 정보 보완과 검수 실적 변경을 같은 사건으로 처리하지 않는다.
7. 이상 수량·사유·사진·작업자를 기록한다.
8. 정상 검수 수량만 입고 작업과 적치 대상으로 전달한다.
