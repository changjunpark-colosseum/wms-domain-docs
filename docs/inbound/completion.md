# 입고 완료

<div class="page-meta"><span>입고</span><span>재고 확정</span><span>9분</span></div>

입고 완료는 모든 정상 수량의 검수·작업·적치와 예외 판정을 끝내고, 하나의 입고 사건을 재고에 최종 반영하는 경계다.

## 완료 조건

1. 입하 결과와 미도착·회송 수량이 종결됐다.
2. 모든 상품의 검수 수량이 확정됐다.
3. 입고 작업의 임시 취급 단위가 모두 처리됐다.
4. 정상 수량이 최종 Location에 적치됐다.
5. 미결 입고 예외가 없다.
6. 같은 입고 주문이 이미 완료되지 않았다.

## 반영 흐름

<div class="flow-strip"><span>완료 조건 검증</span><i>→</i><span>입고 완료 사건</span><i>→</i><span>Inventory 증가</span><i>→</i><span>Location별 Stock 확정</span><i>→</i><span>가용성 판정</span><i>→</i><span>수불 이력</span></div>

## 수량 관계

```text
주문 예정 수량
= 정상 완료 수량 + 예외 종결 수량 + 미도착·회송 수량

정상 완료 수량
= 최종 Location별 Stock 증가 합
```

## Inventory와 Stock

- Inventory는 확정된 입고 사건만큼 증가한다.
- Stock은 SKU Instance·Location별 실물 수량으로 반영한다.
- 정상 Location 적치와 품질 조건을 만족한 수량만 가용재고가 될 수 있다.
- HOLD·불량·예외 수량은 가용재고에 포함하지 않는다.

## 정책

1. 적치 완료만으로 선행 공정과 예외를 무시하지 않는다.
2. 같은 입고 완료 요청을 반복해도 재고를 두 번 증가시키지 않는다.
3. 입고 주문·완료 사건·Inventory·Stock·수불 이력을 하나의 원본 ID로 연결한다.
4. 예외·회송·미도착 수량을 정상 재고 증가에서 제외한다.
5. 완료된 입고 주문의 예정값과 검수 결과를 임의 수정하지 않는다.
6. Inventory와 Stock 반영이 어긋나면 완료 상태만 단독 확정하지 않는다.
7. 완료 후 SKU·LOT·유효기간·Location·수량을 조회할 수 있어야 한다.

## 예외

- 주문 완료지만 Inventory 미증가
- Inventory와 Location별 Stock 합계 불일치
- 같은 입고 사건 중복 반영
- 임시 취급 단위가 남은 상태에서 완료
- 예외 수량이 가용재고에 포함
- 적치되지 않은 수량이 Stock으로 생성
