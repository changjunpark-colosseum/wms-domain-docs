# 입고 예외·TS

<div class="page-meta"><span>입고</span><span>예외작업</span><span>10분</span></div>

입고 예외는 정상 작업 상태와 분리해 유형, 수량, 사유와 판정 결과를 관리한다. TS는 예정 수량과 실제 수량 차이 등을 처리하는 라벨 기반 예외 단위다.

## 예외 흐름

<div class="flow-strip"><span>차이·이상 감지</span><i>→</i><span>TS 라벨 출력</span><i>→</i><span>TS·주문 검색</span><i>→</i><span>실제 수량·사유 확인</span><i>→</i><span>확정 또는 기각</span><i>→</i><span>정상 잔여·종결 반영</span></div>

## 공정별 예외

| 공정 | 예외 |
|---|---|
| 입하 | 부족·초과·회송·입고 형태 불일치 |
| 검수 | 파손·불량·LOT·유효기간 불일치·신청 외 상품 |
| 적치 | 수량 불일치·파손·임시빈 식별 실패 |

## 상태

| 상태 | 설명 |
|---|---|
| 대기 | 판정 전이며 예외 수량이 점유됨 |
| 확정 | 정상 처리 대상에서 제외하거나 인정함 |
| 기각 | 예외 수량을 정상 작업 잔여로 복귀함 |
| 완료 | 후속 수량 반영과 이력 저장이 끝남 |

## 정책

1. 예외 수량은 판정 전에도 다른 작업자가 중복 처리하지 못하게 점유한다.
2. 신청 원장을 실제 수량으로 수정하지 않는다.
3. 확정·기각·수량 조정의 처리자, 시각과 사유를 보존한다.
4. 초과 수량을 자동으로 정상 재고에 포함하지 않는다.
5. 검수 부족은 남은 수량의 종결 여부로 처리한다.
6. Location 정책 위반처럼 시스템이 차단한 오류는 물리 수량 예외와 구분한다.
7. 미결 예외가 있으면 입고 전체 완료를 차단한다.

## 예외

- TS 라벨 분실·중복 발행
- 예외 수량과 실제 수량 불일치
- 승인 없이 초과 수량 반영
- 예외 기각 후 잔여 수량 미복구
- 장기간 판정되지 않은 예외
- 회송 결과가 신청자에게 전달되지 않음
