# 입고 작업

<div class="page-meta"><span>입고</span><span>현장 작업</span><span>10분</span></div>

입고 작업은 입고 주문을 현장에서 처리 가능한 단위로 나누고, 검수된 실물이 적치되기 전까지 작업 상태와 현재 위치를 추적하는 영역이다.

## 핵심 객체

| 객체 | 역할 |
|---|---|
| WRO | 입고 처리 대상 상품·수량과 진행 상태를 묶는 작업 단위 |
| WRO 상품 | 상품별 예정·처리·잔여 수량과 상태 |
| 임시 취급 단위 | 검수 수량을 물리적으로 구분한 묶음 |
| STOWBIN 라벨 | 임시 취급 단위의 상품·LOT·유효기간·수량 식별자 |
| STOW Zone | 검수 완료 임시빈이 최종 적치 전 대기하는 작업 구역 |
| 추가 작업 | Pallet·재포장·부자재 사용 등의 작업 이력 |

CGKR에서는 임시빈을 `ZN-STOW-1`과 같은 STOW Zone에 인계한다. 화면에서는 이 스캔 대상을 `Master Location`이라고 표현하지만 최종 피킹로케이션(`PICK`)·보관로케이션(`STRG`)이나 Location 기준정보의 상위 객체를 의미하지 않는다.

## 객체 관계

```text
Inbound Order
└─ WRO
   ├─ WRO Item
   │  └─ Inspection Result
   │     └─ Temporary Handling Unit · STOWBIN
   │        └─ STOW Zone
   └─ Additional Work
```

<div class="flow-strip"><span>WRO 식별</span><i>→</i><span>미처리 상품 선택</span><i>→</i><span>검수 결과 인수</span><i>→</i><span>임시빈 생성</span><i>→</i><span>STOW Zone 인계</span><i>→</i><span>최종 적치</span></div>

## WRO

WRO는 바코드 스캔으로 찾을 수 있지만 스캔 화면 자체가 WRO의 정의는 아니다. 작업 중단·재진입에서도 완료 상품과 남은 상품을 구분하는 것이 핵심이다.

::: info 현재 CGKR AS-IS — WRO 묶음 범위
입하 단계에서는 WRO 하나를 스캔해도 같은 입고에 연결된 WRO 전체의 입하 작업을 생성·시작하고, 입하 Zone 완료에서도 같은 묶음의 작업을 모두 완료 처리한다. 화면의 WRO 구분과 실제 작업 상태 변경 범위가 다를 수 있다.
:::

### WRO 정책

1. WRO는 하나의 입고 주문과 연결한다.
2. WRO 상품은 주문 상품·예정 수량을 추적할 수 있어야 한다.
3. 완료·진행·잔여 수량을 구분한다.
4. 이미 완료된 상품을 새 작업 대상으로 다시 만들지 않는다.
5. 검수·적치에서는 WRO별 상품 진행을 구분하되, 입하 작업은 같은 입고의 WRO가 묶여 시작·완료될 수 있다.

### 입하 작업 상태 전이

```text
WRO 하나 스캔
→ 같은 입고의 WRO 전체 입하 작업 조회
→ 없는 작업 생성
→ 일반 작업 상태를 진행 중으로 변경
→ 입하 Zone 스캔
→ 같은 묶음의 입하 작업·일반 작업 완료
```

마지막 입고 전체 상태 집계에서는 연결된 입고 작업을 완료 표시하지만 일반 작업 상태는 직접 변경하지 않는다. 두 작업 상태가 다르게 남을 수 있으므로 운영 조회에서 함께 확인해야 한다.

## 임시 취급 단위·STOWBIN

검수된 상품은 최종 적치 전 물리 묶음으로 나눌 수 있다.

```text
모든 STOWBIN 수량 합 = 해당 검수 세부 수량
```

STOWBIN에는 상품·LOT·유효기간이 다른 수량을 섞지 않는다. 출력 실패 시 새 코드를 발번하지 않고 같은 식별자를 다시 출력한다.

## STOW Zone 인계

임시빈 라벨을 `ZN-STOW-1`과 같은 STOW Zone에 인계해 적치 전 소재를 기록한다. STOW는 상품을 보관 위치에 넣는 적치 공정을 뜻하며, STOW Zone은 그 공정에 넘길 상품이 대기하는 구역이다.

```text
검수 완료
→ 임시빈 라벨 부착
→ ZN-STOW-1 스캔
→ STOW Zone 대기
→ 최종 피킹로케이션(PICK)·보관로케이션(STRG) 적치
```

STOW Zone 인계는 최종 적치 완료가 아니다.

## 추가 작업

한 WRO의 상품 처리가 끝나면 사용한 작업 유형·부자재·횟수를 기록할 수 있다. 같은 작업·부자재 조합은 횟수를 합산하며, 추가 작업은 재고 수량을 변경하지 않는다.

## 공통 정책

1. 작업자·시작·종료 시각과 처리 결과를 기록한다.
2. 같은 상품 수량을 여러 작업자가 중복 점유하지 않는다.
3. 임시 취급 단위의 수량 합을 검수 수량과 맞춘다.
4. 임시 취급 단위와 현재 STOW Zone을 함께 조회할 수 있어야 한다.
5. 예외 상품을 정상 STOWBIN으로 처리하지 않는다.
6. 입고 작업 상태와 Inventory 증감 사건을 구분한다.
7. 작업 완료 후 적치되지 않은 임시 취급 단위가 남지 않게 한다.
8. 입하 작업은 WRO 하나가 아니라 같은 입고에 연결된 WRO 묶음으로 변경될 수 있음을 표시한다.
9. 입고 작업 완료 표시와 일반 작업 상태가 일치하는지 확인한다.


## 예외

- WRO·입고 주문 관계 불일치
- 완료 상품 중복 작업
- STOWBIN 수량 합 불일치
- 임시 라벨 중복 발행
- STOW Zone 미인계·오스캔
- 예외 수량이 정상 작업에 혼입
- 추가 작업 중복 기록
