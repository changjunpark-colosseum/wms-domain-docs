# 입고 신청

<div class="page-meta"><span>입고</span><span>예정 등록</span><span>9분</span></div>

입고 신청은 CGKR 안에서 어느 센터에 어떤 상품을 얼마나 보낼지 등록하는 예정 문서다. 저장된 신청은 입고조회와 입하·검수 작업의 기준으로 사용한다.

## 신청 정보

- 화주사
- 입고 센터
- 입고 예정일
- 입고 상품·SKU
- 예정 수량·UOM
- LOT·유효기간 예정값
- 입고 형태와 참고 정보

## 신청 흐름

<div class="flow-strip"><span>CGKR 입고신청</span><i>→</i><span>일반등록 또는 엑셀등록</span><i>→</i><span>기본정보·상품·수량 입력</span><i>→</i><span>첨부파일 등록</span><i>→</i><span>저장</span><i>→</i><span>신청서 번호 확인</span></div>

## 신청 방식

| 방식 | 설명 |
|---|---|
| 일반등록 | 기본정보와 입고상품을 화면에서 직접 선택해 신청 |
| 엑셀등록 | 양식을 내려받아 여러 상품을 파일로 등록 |

## 신청 이후

```text
입고 신청 저장
→ 신청서 번호 생성
→ 입고조회에서 신청 확인·다운로드
→ 입하에서 신청서 코드 스캔
→ RO 기준 입고 작업 처리
```

## 정책

1. 입고 신청은 CGKR 내부의 일반등록 또는 엑셀등록으로 생성한다.
2. 일반등록은 기본정보·입고상품·수량과 첨부파일을 저장한다.
3. 엑셀등록은 지정 양식과 필수 컬럼을 검증한다.
4. 사용 가능한 화주·센터와 상품만 신청 대상으로 허용한다.
5. 저장이 완료되면 입고 신청서 번호를 생성한다.
6. 신청 내용은 입고조회와 신청서 다운로드에서 동일하게 확인돼야 한다.
7. 작업이 시작된 입고 오더의 수정은 허용된 작업 수정 기능을 사용한다.
8. 입하·검수·적치 결과가 신청 원장을 임의로 덮어쓰지 않는다.

## 예외

- 존재하지 않거나 미사용 SKU
- 다른 화주·센터 상품
- 필수 기본정보·수량·UOM 누락
- 잘못된 엑셀 양식·컬럼·데이터 형식
- 첨부파일 등록 실패
- 저장 후 신청서 번호 미생성
- 작업 중인 오더의 허용되지 않은 수정
