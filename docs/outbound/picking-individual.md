# 개별 피킹

<div class="page-meta"><span>출고</span><span>개별 피킹</span><span>8분</span></div>

개별 피킹은 B2C 출고 한 건을 하나의 작업으로 처리한다.

```text
Cart 스캔
→ Location 스캔
→ 상품·수량 스캔
→ 다음 상품 반복
→ PACK Zone 스캔
→ 작업 완료
```

송장번호 개별 피킹은 작업 진입 시 송장을 사용하지만 상품의 물리 스캔 순서는 일반 개별 피킹과 같다.

## 정책

1. 하나의 작업은 하나의 출고 주문을 처리한다.
2. 작업 시작 시 사용할 Cart를 연결한다.
3. 안내된 Location과 상품 순서로 스캔한다.
4. 피킹 수량은 상품별 계획 수량을 초과할 수 없다.
5. 완료된 상품은 다시 스캔해 중복 수량을 만들지 않는다.
6. 모든 상품 완료 후 Cart를 PACK Zone에 인계한다.
7. 작업 중 재고가 없으면 정상 수량을 임의로 줄이지 않고 재고부족 처리한다.

## 예외

- 잘못된 Cart
- Location·상품 불일치
- 계획수량 초과 스캔
- 상품 실물 부족
- PACK Zone 오스캔
- 작업 중단 후 재진입
