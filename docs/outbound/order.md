# 출고 신청·주문

<div class="page-meta"><span>출고</span><span>주문 원장</span><span>9분</span></div>

출고 신청은 어떤 상품을 몇 개, 누구에게, 어떤 배송 방식으로 보낼지 등록하는 출고 작업의 원장이다.

## 주문 정보

- 화주·센터
- B2C·B2B 출고 유형
- 판매번호·출고번호
- 수취인·배송지
- 출고 상품·SKU·수량
- 택배사·배송 방식
- 출고 요청일·마감 정보
- 작업 메모·부가 작업

## 생성 흐름

<div class="flow-strip"><span>출고 정보 입력</span><i>→</i><span>상품·수량 등록</span><i>→</i><span>배송 정보 확인</span><i>→</i><span>재고·필수값 검증</span><i>→</i><span>출고번호 생성</span><i>→</i><span>작업 생성 대상 등록</span></div>

## 정책

1. 출고번호는 센터 안에서 유일해야 한다.
2. 사용 가능한 화주·센터·SKU만 등록한다.
3. 주문 수량은 0보다 커야 한다.
4. B2C·B2B 유형별 필수 배송·작업 정보를 검증한다.
5. 출고 신청 수량과 실제 피킹·패킹·완료 수량을 덮어쓰지 않고 따로 보존한다.
6. 작업 생성 이후 상품·수량 변경은 기존 작업과 재고 계획을 함께 정리해야 한다.
7. 완료된 출고 주문의 상품·수량·수취 정보를 직접 수정하지 않는다.
8. 엑셀·연동 다건 등록에서 행별 오류와 전체 처리 결과를 확인할 수 있어야 한다.

## 상태

| 상태 | 설명 |
|---|---|
| 출고대기 | 주문 생성 후 작업 미생성 |
| 작업대기 | 피킹 작업 생성·작업자 대기 |
| 작업중 | 피킹·패킹 진행 중 |
| 출고완료 | 상차·재고 차감 완료 |
| 취소 | 출고 작업 중단·재고 복구 |

## 예외

- 미사용 SKU·화주·센터
- 출고 수량 0 또는 음수
- 재고 부족
- 수취인·배송지 필수값 누락
- 중복 판매번호·출고번호
- 작업 중 주문 변경
- 완료 주문 취소 시도
