# 출고 완료

<div class="page-meta"><span>출고</span><span>재고 차감</span><span>9분</span></div>

출고 완료는 상차·인계한 상품을 창고 재고에서 최종 차감하고 출고 주문을 종결하는 단계다.

## 완료 흐름

<div class="flow-strip"><span>상차 결과 확인</span><i>→</i><span>중복 완료 확인</span><i>→</i><span>Stock 차감</span><i>→</i><span>Inventory 차감</span><i>→</i><span>수불부 출고 기록</span><i>→</i><span>출고 상태·실제 발송일 완료</span></div>

## 재고 반영

```text
Stock: 피킹·패킹한 실제 상품 수량 감소
Inventory: 출고 완료 수량만큼 장부 감소
수불부: B2C 또는 B2B 출고 수량 기록
```

## 정책

1. 하나의 출고 주문은 한 번만 완료한다.
2. 완료 수량은 피킹·패킹·상차한 수량과 일치해야 한다.
3. Stock 차감과 Inventory 차감은 함께 성공하거나 함께 실패해야 한다.
4. 현재 수량보다 큰 출고 차감을 허용하지 않는다.
5. 출고번호·작업번호·송장번호와 재고 이력을 연결한다.
6. 처리자와 실제 발송일을 기록한다.
7. 완료 상태 저장과 재고 차감이 어긋나면 재처리·대사할 수 있어야 한다.
8. 이미 완료된 요청을 재처리하면 기존 완료 결과를 반환하고 다시 차감하지 않는다.

## 예외

- Stock·Inventory 수량 부족
- 피킹·패킹 수량 불일치
- 재고 차감 성공 후 상태 저장 실패
- 상태 완료 후 수불부 누락
- 동일 출고 중복 완료
- 일부 Box·송장만 상차됨
