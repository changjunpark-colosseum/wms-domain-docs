# 작업 생성·할당

<div class="page-meta"><span>출고</span><span>피킹 작업</span><span>10분</span></div>

작업 생성은 선택한 출고를 개별·클러스터·총량 피킹 단위로 묶고 피킹할 Stock 수량을 계획하는 과정이다.

## 방식별 작업 단위

| 방식 | 작업 구성 | 작업자 지정 단위 |
|---|---|---|
| 개별 | 출고 1건 : 작업 1건 | 피킹 작업 |
| 송장번호 개별 | 개별과 같은 작업 구성 | 피킹 작업 |
| 클러스터 | 여러 출고 : 작업 1건 | 피킹 작업 |
| 송장번호 클러스터 | 클러스터와 같은 구성 | 피킹 작업 |
| 총량 | 여러 출고 : 상위 작업 1건 | 피킹 슬립 |
| B2B | B2B 출고 상품·수량으로 작업 생성 | B2B 피킹 작업 |

## 생성 흐름

<div class="flow-strip"><span>출고 선택</span><i>→</i><span>피킹 방식 선택</span><i>→</i><span>대상 Zone Stock 조회</span><i>→</i><span>가용수량 확인</span><i>→</i><span>작업·상세 생성</span><i>→</i><span>작업번호 발번</span></div>

## Zone별 재고 할당

| 출고 유형 | 작업 생성 시 대상 Zone | 선택 가능 여부 |
|---|---|---|
| B2C | 피킹로케이션(`PICK`) | 고정. 보관로케이션(`STRG`) Stock은 직접 할당하지 않음 |
| B2B 기본 | 피킹로케이션(`PICK`) + 보관로케이션(`STRG`) | 두 Location 유형의 가용 Stock 사용 |
| B2B 피킹 존 피킹 | 피킹로케이션(`PICK`) | 관리자가 옵션을 선택하면 피킹로케이션(`PICK`)으로 제한 |

실제 Stock을 할당하는 Location 유형 조건은 피킹지시 생성 시 적용한다. B2C 상품이 보관로케이션(`STRG`)에만 있으면 먼저 피킹로케이션(`PICK`)으로 보충해야 한다. B2B는 기본 설정에서 보관로케이션(`STRG`) Stock을 피킹 작업에 직접 포함할 수 있다.

## 재고 지정 유형

| 코드 | 할당 기준 |
|---|---|
| `GEN` | 상품 기준 일반 할당 |
| `SEL` | 지정한 유효기간과 같은 Stock |
| `LOT` | 지정한 LOT와 같은 Stock |
| `SLT` | 지정한 유효기간·LOT 조건을 모두 적용 |

지정 조건을 통과한 Stock 안에서는 유효기간, LOT, UOM 우선순위와 가용수량 순으로 할당한다.

## 작업자 할당

```text
관리자: 미배정 작업 선택 → 작업자 지정
작업자: 가져갈 수 있는 작업 선택·스캔 → 내 작업으로 가져오기
```

총량 피킹에서는 상위 작업 전체가 아니라 작업자가 수행할 피킹 슬립을 할당한다.

## 정책

1. 작업과 작업자는 같은 창고에 속해야 한다.
2. 하나의 작업 또는 슬립에는 한 명의 작업자만 지정한다.
3. 여러 작업자가 동시에 가져오면 먼저 성공한 한 명에게만 할당한다.
4. 이미 다른 작업자에게 할당된 작업은 가져올 수 없다.
5. 종료·취소·예외 완료 작업은 다시 할당하지 않는다.
6. 작업 생성 수량은 현재 가용 Stock 수량을 초과할 수 없다.
7. 작업 생성 시 사용 수량과 출고 계획 수량을 함께 기록한다.
8. 작업자 지정 후 작업은 `WAIT` 상태에서 시작한다.
9. B2C 작업은 피킹로케이션(`PICK`)의 가용 Stock만 할당한다.
10. B2B 작업은 기본적으로 피킹로케이션(`PICK`)·보관로케이션(`STRG`)을 사용하고, `피킹 존 피킹` 선택 시 피킹로케이션(`PICK`)만 할당한다.
11. 실제 할당된 Stock ID·Location 유형·계획 수량을 작업 상세에 보존한다.
12. B2C 피킹로케이션(`PICK`) 재고가 부족하고 보관로케이션(`STRG`)에 재고가 있으면 보충과 피킹지시 생성의 순서를 구분한다.
13. 지정출고 유형의 유효기간·LOT 조건을 시뮬레이션과 실제 할당에 동일하게 적용한다.


## 작업 목록

| 목록 | 포함 조건 |
|---|---|
| 할당된 작업 | 현재 사용자에게 배정된 WAIT·작업중 작업 |
| 가져갈 수 있는 작업 | 같은 창고의 미배정 작업 |
| 총량 슬립 | 현재 사용자에게 배정된 총량 슬립 |

## 예외

- 다른 창고 작업·작업자
- 작업번호 없음
- 다른 작업자에게 먼저 할당됨
- 이미 완료·취소된 작업
- 재고 부족으로 작업 생성 실패
- B2C 보관로케이션(`STRG`) 재고를 피킹 작업에 직접 할당
- B2B Zone 옵션과 실제 할당 Location 불일치
- 총량 상위 작업 전체에 작업자 지정 시도
