# 클러스터 피킹

<div class="page-meta"><span>출고</span><span>클러스터 피킹</span><span>9분</span></div>

클러스터 피킹은 여러 B2C 출고 주문을 하나의 작업으로 묶고, 주문마다 Con을 연결해 동시에 집품·분류한다.

```text
Cart 스캔
→ 주문별 Con 연결
→ Location 스캔
→ 상품 스캔
→ 넣을 Con 스캔
→ 주문별 수량 처리
→ PACK Zone 인계
```

## 정책

1. 작업 시작 전에 Cart와 주문별 Con 관계를 확정한다.
2. 하나의 Con은 작업 안에서 하나의 출고 주문에만 연결한다.
3. 상품 스캔 후 넣을 Con과 수량을 확인한다.
4. 주문별 계획 수량과 전체 피킹 수량을 함께 보존한다.
5. 일부 주문이 완료돼도 전체 작업의 남은 주문을 계속 처리할 수 있다.
6. Con 오투입은 수량을 확정하지 않고 올바른 Con을 다시 확인한다.
7. 모든 Con 처리가 끝난 뒤 PACK Zone에 인계한다.

## 예외

- Con 중복·다른 주문 연결
- 상품을 잘못된 Con에 투입
- 일부 주문 재고 부족
- Cart·Con 분실·교체
- 완료된 Con에 추가 스캔
