# 총량 피킹

<div class="page-meta"><span>출고</span><span>총량 피킹</span><span>9분</span></div>

총량 피킹은 여러 B2C 출고 주문이 요구한 동일 SKU 수량을 주문별로 구분하지 않고 합계로 피킹한다.

```text
주문 A 2EA + 주문 B 3EA + 주문 C 1EA
→ 총량 피킹 6EA
→ 후속 패킹에서 주문별 분배
```

## 작업 구조

- 여러 출고를 하나의 상위 총량 작업으로 묶는다.
- 작업자가 수행할 수량은 피킹 슬립으로 분리한다.
- 각 슬립에 작업자와 Con을 연결한다.

## PDA 흐름

```text
피킹 슬립 선택·가져오기
→ Con 스캔
→ Location 스캔
→ 상품·총량 스캔
→ PACK Zone 스캔
→ 슬립 완료
```

## 정책

1. 작업자 할당은 상위 작업이 아니라 피킹 슬립 단위로 한다.
2. 슬립마다 하나의 Con과 한 명의 작업자를 연결한다.
3. 모든 슬립의 피킹 수량 합은 상위 작업 계획 수량과 일치해야 한다.
4. 총량 피킹 수량과 패킹에서 주문별로 분배한 수량을 대사한다.
5. 일부 슬립의 완료가 상위 작업 전체 완료를 의미하지 않는다.
6. 재고부족·취소 시 영향을 받는 주문별 수량을 확인할 수 있어야 한다.

## 예외

- 피킹 슬립 중복 가져오기
- Con 미연결·중복 연결
- 슬립 합계와 상위 작업 합계 불일치
- 총량 피킹 후 주문별 분배 부족
- 일부 출고 취소로 계획 수량 변경
