# 패킹

<div class="page-meta"><span>출고</span><span>패킹 검수</span><span>10분</span></div>

패킹은 PACK Zone으로 인계된 피킹 상품을 주문과 다시 비교하고 배송 가능한 Box로 구성하는 작업이다.

## 패킹 흐름

<div class="flow-strip"><span>Cart·Con·작업번호 스캔</span><i>→</i><span>주문·내용물 확인</span><i>→</i><span>상품·수량 검수</span><i>→</i><span>Box·무게 입력</span><i>→</i><span>송장 스캔·부착</span><i>→</i><span>완료 또는 NG</span></div>

## 핵심 정보

- 출고번호·판매번호
- 패킹 작업자
- 피킹 인계 상품·수량
- Box와 Box별 내용물
- 무게·부자재·부가 작업
- 패킹 슬립
- 송장번호

## 정책

1. 주문 하나에는 동시에 하나의 활성 패킹 작업만 허용한다.
2. 패킹 수량은 피킹 인계 수량을 초과할 수 없다.
3. Box별 상품·수량·무게와 송장 관계를 보존한다.
4. 한 주문을 여러 Box로 분할 포장할 수 있다.
5. 분할 Box마다 유효한 송장과 내용물을 연결한다.
6. 내용물 불일치·파손은 정상 완료하지 않고 NG로 기록한다.
7. 프린터·패킹 슬립 출력 실패는 재고 수량을 변경하지 않는다.
8. 패킹 완료는 상차·출고 완료가 아니다.

## B2B 차량출고 패킹

```text
Con 또는 피킹 슬립 스캔
→ 패킹 슬립 출력·스캔
→ 상품 수량 스캔·입력
→ 부가 작업 추가
→ 포장 수량·Box 종류
→ 카톤 라벨 전체·요약 출력
→ 작업자 기록
→ B2B 작업 완료
```

B2B 부가 작업, 카톤 라벨과 작업자 정보는 일반 B2C 패킹과 분리해 보존한다.

B2B 차량 출고에는 택배 송장을 발행하지 않는다. 패킹 슬립과 전체·요약 카톤 라벨을 출력하고 Box·작업 수량과 차량 출고 정보를 기준으로 완료한다.

## 상태

| 상태 | 설명 |
|---|---|
| 대기 | 피킹 인계 완료·패킹 미시작 |
| 패킹 중 | 작업자가 주문을 점유해 검수·포장 중 |
| 완료 | 내용물·Box·필수 송장 조건 충족 |
| NG | 불일치·파손·재작업 판단 필요 |

## 예외

- 다른 작업자가 같은 주문 패킹
- 피킹 수량과 실물 불일치
- 주문 외 상품 혼입
- Box 중량·부피 초과
- 분할 Box 일부 송장 누락
- 패킹 슬립·라벨 출력 실패
