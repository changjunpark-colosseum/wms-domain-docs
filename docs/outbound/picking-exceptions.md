# 예외 피킹·재고부족

<div class="page-meta"><span>출고</span><span>피킹 예외</span><span>9분</span></div>

B2C 피킹에서 재고부족은 시스템에 계획된 수량과 피킹로케이션(`PICK`)의 실제 수량이 다른 상태다. 작업을 정상 완료로 숨기지 않고 부족 수량과 원인을 기록한다.

## 재고부족 흐름

<div class="flow-strip"><span>실물 부족 확인</span><i>→</i><span>STKOUT 등록</span><i>→</i><span>피킹 상세 EXCEPTION</span><i>→</i><span>출고 수량 조정·재고 확인</span><i>→</i><span>예외 피킹 생성</span><i>→</i><span>재피킹 또는 종결</span></div>

## 정책

1. 부족 수량을 실제 피킹 완료 수량으로 처리하지 않는다.
2. 작업번호·SKU·Location·계획수량·실제수량과 사유를 기록한다.
3. 정상 처리한 수량과 부족 수량을 구분한다.
4. 재고를 다시 확보하면 예외 피킹 작업으로 남은 수량을 처리한다.
5. 작업 중단·재진입에서 이미 처리한 수량을 중복 스캔하지 않는다.
6. 오피킹은 잘못 집은 상품을 원위치 또는 지정 Location으로 복구한 뒤 재작업한다.
7. 부족 처리가 출고 주문 수량 변경으로 이어지면 주문·작업·패킹 대상에 함께 반영한다.

## 예외

- STKOUT 중복 등록
- 다른 Location에 재고가 존재함
- 부족 수량보다 큰 예외 피킹 생성
- 작업 취소 후 예외 작업이 남음
- Stock 조정과 예외 피킹이 중복 반영됨
