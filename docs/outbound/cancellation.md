# 취소·재고 복구

<div class="page-meta"><span>출고</span><span>취소·보상</span><span>9분</span></div>

출고 취소는 주문 상태만 바꾸는 일이 아니다. 현재 진행 단계에서 생성한 작업, 계획 수량, 피킹 재고와 송장을 함께 정리해야 한다.

## 단계별 복구

| 취소 시점 | 복구 내용 |
|---|---|
| 작업 생성 전 | 출고 주문만 취소 |
| 작업 생성 후·미시작 | 피킹 작업·상세 롤백, 계획 수량 복구 |
| 작업자 할당 후 | 작업자 점유 해제 |
| 피킹 시작 후 | 작업 생성 전 상태로 롤백할 수 없음. 진행 취소·예외·재고 복구 절차 사용 |
| 패킹 후 | 패킹 작업·Box·내용물 관계 정리 |
| 송장 발번 후 | 송장 무효화·출력물 폐기 |
| 출고 완료 후 | 일반 취소 대신 반품·관리자 조정 검토 |

## 정책

1. 현재 출고 상태와 완료 수량을 확인한 뒤 취소한다.
2. 작업 생성으로 감소한 가용수량·증가한 계획수량을 복구한다.
3. 피킹 완료 상품은 실제 소재를 확인하고 원위치 또는 지정 Location으로 이동한다.
4. 송장을 무효화해 같은 화물이 배송되지 않게 한다.
5. 완료된 작업과 수량 이력을 삭제하지 않고 취소 이력을 남긴다.
6. 같은 취소 요청을 반복해도 수량을 두 번 복구하지 않는다.
7. 일부 상품·Box만 처리된 경우 취소 가능 범위를 명확히 한다.

## 피킹 작업 롤백

피킹 작업을 제거하고 작업 생성 전 상태로 되돌리는 롤백은 다음 조건에서만 가능하다.

| 조건 | 롤백 |
|---|---|
| 일반 주문·피킹 미시작 | 가능 |
| 배치 주문 | 불가 |
| 피킹 시작됨 | 불가 |

배치 주문이나 실제 피킹이 시작된 주문을 단순 롤백하지 않는다. 이 경우 현재 처리 수량과 소재를 기준으로 별도의 취소·예외·복구 흐름을 사용한다.


## 예외

- 피킹 중 작업자와 취소 동시 실행
- PACK Zone 재고의 원위치 불명확
- 송장 무효화 실패
- 취소 후 가용수량 미복구
- 일부 Box 이미 상차됨
- 출고 완료 뒤 일반 취소 요청
- 배치 주문의 피킹 작업 롤백
- 피킹 시작 후 작업 생성 전 상태로 롤백
