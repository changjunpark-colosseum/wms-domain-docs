# 상차

<div class="page-meta"><span>출고</span><span>물리 인계</span><span>8분</span></div>

상차는 패킹과 송장이 완료된 화물을 차량 또는 택배사에 실제로 인계하는 작업이다.


## 상차 흐름

<div class="flow-strip"><span>패킹 완료 대상 조회</span><i>→</i><span>출고·송장 선택</span><i>→</i><span>피킹·패킹·송장 조건 확인</span><i>→</i><span>차량·택배사 인계</span><i>→</i><span>상차 완료</span></div>

## 상차 조건

- 피킹 완료
- 패킹 완료
- 송장 필수 주문의 유효 송장 존재
- 미해결 NG·재고부족 없음
- 이미 상차 완료되지 않은 주문

## 정책

1. 실제 인계한 출고만 상차 완료 처리한다.
2. 송장 필수 주문은 유효한 송장을 확인한다.
3. B2B 차량 출고는 송장을 요구하지 않고 패킹 슬립·카톤 라벨·차량 인계 조건을 적용한다.
4. 상차 처리자와 실제 발송일을 기록한다.
5. 일괄 상차에서는 조건을 충족한 출고와 실패한 출고를 구분한다.
6. 같은 출고를 두 번 상차 완료하지 않는다.
7. 물리 인계 결과와 시스템 완료 대상이 다르면 대사할 수 있어야 한다.

## 예외

- 피킹·패킹 미완료
- 송장 필수 주문의 미발번·미부착
- 패킹 NG·재고부족 미해결
- 이미 완료된 출고 재처리
- 일부 대상만 조건 충족
- 물리 인계 후 시스템 반영 실패
