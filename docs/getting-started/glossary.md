# 핵심 용어

<div class="page-meta"><span>시작하기</span><span>용어</span><span>8분</span></div>

## 상품

| 용어 | 의미 |
|---|---|
| Product | 고객에게 인식되는 상품군 |
| SKU | 재고와 주문에서 구분하는 판매·출고 단위 |
| SKU Instance | LOT·유효기간 등 재고 속성이 확정된 실물 식별 단위 |
| Barcode | 스캔으로 상품·Location·운반체를 식별하는 코드 |
| UOM | EA·BOX·PLT처럼 수량을 세는 단위 |

## 재고

| 용어 | 의미 |
|---|---|
| Inventory | 확정된 입출고 사건을 반영한 장부 재고 |
| Stock | 특정 공간에 존재하는 실물 수량과 상태 |
| Available | 신규 출고에 할당할 수 있는 재고 |
| HOLD | 검토·품질·운영 사유로 사용을 보류한 재고 또는 공간 |
| LOT | 같은 생산·입고 조건을 공유하는 상품 묶음 |
| 수불부 | 재고 증가·감소 원인과 전후 수량을 시간순으로 기록한 장부 |

## 공간과 운반체

| 용어 | 의미 |
|---|---|
| Zone | 같은 작업 목적과 정책을 공유하는 공간 묶음 |
| Location | Stock이 귀속되고 작업자가 스캔하는 창고 주소 |
| Aisle·Bay·Tier·Slot | 통로·랙 구간·높이 단·최소 칸으로 Location을 구성하는 계층 |
| LPN | 하나의 단위로 이동·추적하는 재고 묶음의 식별자 |
| Cart | 여러 상품·Con을 운반하는 작업 도구 |
| Con·Container | 작업 안에서 주문이나 상품을 구분해 담는 용기 |
| PACK Zone | 피킹 완료 재고를 패킹 작업에 인계하는 구역 |

## 입고

| 용어 | 의미 |
|---|---|
| 입하 | 센터에 도착한 화물을 확인하고 인수하는 단계 |
| 검수 | 신청 정보와 실물의 상품·수량·상태를 비교해 확정하는 단계 |
| 적치 | 검수된 재고를 보관·피킹 Location에 배치하는 작업 |

## 출고

| 용어 | 의미 |
|---|---|
| 피킹 | 출고할 상품을 Location에서 찾아 집는 작업 |
| 패킹 | 주문·상품·수량을 확인하고 Box를 구성하는 작업 |
| 송장 | Box와 택배 운송을 연결하는 운송번호와 라벨 |
| 상차 | 패킹된 화물을 차량이나 택배사에 인계하는 작업 |

## 반품

| 용어 | 의미 |
|---|---|
| 반입 | 회수된 상품을 원출고와 연결해 RETURN Zone으로 들이는 단계 |
| 클레임 확정 사유 | 센터가 반품 실물을 확인한 뒤 확정하는 표준 사유 코드 |
| 관리자 사유 | SKU별 특이사항을 작업자가 자유롭게 기록하는 보충 설명 |
| 화주사 확인 | 센터가 등록한 반품 수량·사유·사진을 화주사가 확인하고 작업 재개를 승인하는 선택 절차 |
| 품질 판정 | 반품 상품을 양품·보류·불량으로 나누는 단계 |
| 양품화 | 반품 상품을 정상 판매 가능한 재고로 복귀시키는 처리 |
