# 수불부

<div class="page-meta"><span>재고</span><span>이력·마감</span><span>10분</span></div>

수불부는 현재 수량만 보여주는 조회가 아니라 **어떤 업무 때문에 재고가 증가하거나 감소했는지** 설명하는 장부다.

## 조회 유형

### 상품별 수불부

Product·SKU·LOT·유효기간을 기준으로 입고·출고와 일자별 마감 재고를 조회한다.

### Location별 수불부

특정 Location의 이전 재고, 증가·감소 내역과 당일 재고를 조회한다.

## 수량 관계

```text
기초 재고
+ 입고
+ 반품·관리자 증가
- 출고
- 폐기·관리자 감소
= 마감 재고
```

## 검색 조건

- 기간
- 화주·센터
- Product·SKU
- LOT·유효기간
- Location
- 입출고 유형

## 정책

1. 수불 행은 원인이 된 입고·출고·조정 작업과 연결한다.
2. 기간 시작 재고와 종료 재고의 연결이 끊기지 않아야 한다.
3. 거래가 없어도 재고가 남아 있으면 마감 행을 제공할 수 있다.
4. 과거 마감 결과를 현재 수량으로 소급 덮어쓰지 않는다.
5. 관리자 입출고, 가용재고 조정과 폐기를 서로 다른 유형으로 표시한다.
6. 이동은 센터 전체 총수량을 바꾸지 않지만 Location별 수불에는 출발·도착 이력으로 표시한다.
7. HOLD·해제는 총수량 수불과 상태 변경 이력을 구분한다.
8. 다운로드는 화면의 검색·정렬·권한 조건을 그대로 적용한다.

## 대사

다음 값이 맞지 않으면 원인 작업을 조사한다.

- Product 합계와 SKU 합계
- SKU 합계와 Location별 Stock 합계
- 전일 마감과 당일 기초 재고
- 입출고 작업 수량과 수불 반영 수량

## 예외

- 마감 배치 누락·중복
- 늦게 도착한 과거 거래
- 작업은 완료됐지만 수불 행이 없음
- 다운로드 합계와 화면 합계 불일치
- Location 이동이 총입출고로 잘못 집계됨
