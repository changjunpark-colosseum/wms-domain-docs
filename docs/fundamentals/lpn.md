# LPN과 재고 계보

<div class="page-meta"><span>재고</span><span>식별자</span><span>10분</span></div>

LPN(License Plate Number)은 **팔레트·박스·토트 같은 취급 단위에 담긴 재고 묶음을 추적하는 고유 식별자**입니다.

## LPN과 물리 용기

LPN은 그릇의 외형보다 그 안의 재고 묶음과 계보를 식별합니다. 물리 용기를 재사용하더라도 재고 묶음의 입고회차·LOT·수량 이력은 분리해서 추적할 수 있어야 합니다.

| 대상 | 식별하는 것 |
|---|---|
| LPN | 하나의 재고 묶음과 수량 계보 |
| Tote·Pallet | 재사용 가능한 물리 용기 |
| Cart·Carrier | 여러 재고를 운반하는 이동 수단 |
| 송장번호 | 택배사가 운송할 화물 |

## 공정별 역할

<div class="flow-strip"><span>검수에서 발번</span><i>→</i><span>적치하며 위치 변경</span><i>→</i><span>피킹 중 잠금</span><i>→</i><span>분할·병합 계보</span><i>→</i><span>소진·종결</span></div>

## 수량 보존

```text
부모 LPN 10 EA
→ 부모 잔량 7 EA
→ 자식 LPN 3 EA

7 + 3 = 10
```

부분 이동에서 자식 LPN을 만든다면 `parentLpnId`, 원본 수량, 처리 수량과 대상 Location을 연결해야 합니다. 피킹처럼 일시적인 작업 버킷 이동에서는 새 LPN 대신 같은 묶음의 상태만 바꾸는 모델도 가능합니다.

## 할당과 잠금

- **할당**은 주문에 수량을 예약하는 장부 행위입니다.
- **잠금**은 특정 물리 작업이 LPN을 독점하는 실행 행위입니다.

할당만으로 LPN 전체를 잠그면 다른 주문이 남은 가용 수량을 예약하지 못할 수 있습니다. 반대로 물리 작업 시작 후 잠금이 없으면 두 작업자가 같은 LPN을 동시에 집품할 수 있습니다.

## 주요 정책

1. 하나의 LPN에 서로 다른 SKU Instance를 섞을지 명시합니다.
2. 분할 전후 수량 합은 항상 같습니다.
3. LOT·유효기간·소유자 같은 정체성 속성은 이동해도 유지됩니다.
4. 작업 중단 시 잠금뿐 아니라 WIP 수량도 복구합니다.
5. 외부 팔레트 번호나 SSCC는 내부 LPN과 참조 관계로 보존할 수 있습니다.

## 예외 상황

- 라벨 훼손으로 재발행할 때 기존 LPN을 중복 생성하지 않습니다.
- 수량이 0이 된 가상 LPN은 재사용하지 않습니다.
- 물리 용기 파손과 내용물 재고의 품질 판정을 별도로 처리합니다.
- 병합이 허용되더라도 LOT·유효기간이 다른 재고를 한 묶음으로 합치지 않습니다.
