# 배송 추적·반품 연계

송장번호는 배송 상태를 조회하고 반품 시 원출고·상품을 찾는 기준 식별자다.

## 연결 관계

```text
송장번호
→ 택배사·배송 상태
→ 출고 주문·Box
→ Box 내용물·SKU·수량
→ 반품 가능 상품·수량
```

## 정책

1. 송장과 원출고·Box·상품 관계를 보존한다.
2. 배송 상태 응답과 마지막 확인 시각을 저장한다.
3. 무효 송장은 현재 배송 추적 정본으로 사용하지 않는다.
4. 반품 신청은 유효한 원송장과 출고 완료 상품을 기준으로 한다.
5. 누적 반품 수량이 원출고 수량을 초과하지 않게 한다.
6. RTS는 원송장과 배송사 반송 상태를 함께 연결한다.

## 예외

- 송장과 출고 관계 없음
- 무효·교체된 송장으로 반품 생성
- 배송 상태 장기 미갱신
- 원출고보다 큰 반품 수량
