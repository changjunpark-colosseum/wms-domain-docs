# 자체송장·임시송장

## 자체송장

운영자가 송장번호·택배사 정보와 첨부파일을 직접 등록한다.

- 필수 송장정보와 첨부파일을 검증한다.
- API를 통하지 않은 송장은 연동 출력 가능 여부를 별도로 표시한다.
- 주문·Box와 등록한 송장번호를 연결한다.

## 임시송장

실제 택배사 운송번호가 발번되지 않은 주문에 임시 출력물을 제공한다.

- 실제 송장번호와 명확히 구분한다.
- 상품번호·UPC·주소 등 임시 출력 정보를 표시한다.
- 임시송장을 출고 완료용 실제 송장으로 간주하지 않는다.

## 정책

1. 자체송장과 임시송장의 유형을 명시한다.
2. 실제 택배사 송장과 번호·출력 이력을 섞지 않는다.
3. 자체송장 정보 변경 전후 값을 보존한다.
4. B2B 차량 출고는 자체·임시 택배 송장 발행 대상이 아니다.

## 예외

- 자체송장 필수 정보·첨부 누락
- 동일 송장번호 중복 등록
- 임시송장을 실제 배송 추적번호로 사용
- API 미연동 송장의 출력 시도
