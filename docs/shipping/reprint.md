# 송장 재출력

재출력은 새 송장번호를 만들지 않고 기존 유효 송장을 다시 인쇄하는 작업이다.

## 정책

1. 발번된 B2C 송장만 재출력한다.
2. 재출력 전후 송장번호는 동일해야 한다.
3. 일반·순차 출력 방식을 선택할 수 있다.
4. 사용자가 선택한 송장 식별자를 출력 완료까지 유지한다.
5. 재출력 횟수·사유·처리자·시각을 기록한다.
6. B2B 주문과 미발번 주문은 재출력하지 않는다.

## 재출력과 재발번

```text
재출력: 기존 송장번호 유지
재발번: 기존 송장 무효화 + 새 송장번호 생성
```

## 예외

- 미발번 주문 재출력
- 무효 송장 재출력
- 선택한 송장 대신 다른 추가 송장 출력
- 재출력을 새 송장으로 등록
