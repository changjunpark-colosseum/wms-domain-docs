# 택배사 변경·재발번

## 흐름

<div class="flow-strip"><span>기존 송장 선택</span><i>→</i><span>새 택배사 선택</span><i>→</i><span>주소·계약 검증</span><i>→</i><span>기존 송장 무효화</span><i>→</i><span>새 송장 발번</span><i>→</i><span>새 라벨 출력</span></div>

## 정책

1. B2C 유효 송장만 택배사 변경 대상으로 한다.
2. 새 택배사의 계약·주소·배송 조건을 다시 검증한다.
3. 기존 송장을 무효화하고 새 번호를 연결한다.
4. 기존·신규 송장 관계와 변경 사유를 보존한다.
5. 변경 실패 시 두 송장이 모두 유효한 상태로 남지 않게 한다.
6. B2B 주문은 택배사 변경·재발번 대상이 아니다.

## 예외

- 새 택배사 주소 정제 실패
- 기존 송장 무효화 실패
- 새 송장 발번 실패
- 기존·신규 송장 동시 유효
- 이미 상차된 주문의 택배사 변경
