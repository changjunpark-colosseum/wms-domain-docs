# 송장 출력

## 출력 방식

| 방식 | 설명 |
|---|---|
| 일반 출력 | 화면 목록 표시 순서로 출력 |
| 순차 출력 | 단일 SKU 주문부터 복수 SKU 주문 순서로 출력 |

## 흐름

<div class="flow-strip"><span>출고 선택</span><i>→</i><span>송장 출력</span><i>→</i><span>택배사 선택</span><i>→</i><span>일반·순차 출력</span><i>→</i><span>출력신청목록</span><i>→</i><span>출력 결과 확인</span></div>

## 정책

1. 발번된 B2C 송장만 출력한다.
2. 선택한 주문·송장과 실제 출력 번호가 일치해야 한다.
3. 복수 출력 순서를 화면과 동일하게 재현한다.
4. 출력 요청·결과·프린터·처리시각을 기록한다.
5. 출력 실패가 송장 발번 결과를 무효화하지 않는다.
6. B2B 주문은 송장 출력 대상에서 제외한다.

## 예외

- 미발번 송장 출력
- 다른 송장번호 출력
- 프린터 연결·상태 오류
- 복수 출력 순서 불일치
- 출력 성공 여부 미확인
