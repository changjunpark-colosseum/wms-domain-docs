# 추가 송장

추가 송장은 하나의 B2C 주문을 여러 Box로 분할할 때 두 번째 이상의 운송번호를 연결하는 기능이다.

## 흐름

```text
기존 송장 발번 확인
→ 추가 Box 확인
→ 추가 송장 생성
→ 개별 송장번호 저장
→ 선택 송장 출력·부착
```

## 정책

1. 기존 송장이 발번된 B2C 주문에만 추가 송장을 생성한다.
2. B2B 주문은 추가 송장 대상에서 제외한다.
3. 추가 송장마다 Box·내용물 관계를 연결한다.
4. 추가 송장 출력은 사용자가 선택한 개별 송장번호를 유지한다.
5. 주문 ID만으로 재조회해 다른 송장을 출력하지 않는다.
6. 주문의 유효 송장 목록과 무효 송장을 구분한다.

## 송장번호 스캔 검증

대표 송장과 추가 송장은 스캔 시 기존 연결 관계를 다르게 검증한다.

| 구분 | 검증 |
|---|---|
| 대표 송장 | 스캔한 송장번호와 연결된 출고 주문이 존재해야 함 |
| 추가 송장 | 이미 다른 출고에 연결된 송장번호를 사용할 수 없음 |
| 공통 | 같은 송장번호가 여러 대기 주문이나 작업 중 주문에 중복 연결되면 진행 불가 |

중복이 발견되면 임의로 하나를 선택하지 않고 기존 송장 매핑을 정리한 뒤 다시 스캔한다.


## 예외

- 미발번 주문의 추가 송장 생성
- 분할 Box 없는 주문
- 같은 Box의 송장 중복
- 선택한 추가 송장 식별자 유실
- 다른 추가 송장 오출력
- 이미 다른 출고에 연결된 추가 송장번호
- 하나의 송장번호가 여러 대기·작업중 출고에 중복 연결됨
