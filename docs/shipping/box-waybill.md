# Box·송장 연결

```text
주문 1
├─ Box A ─ 송장 1 ─ 상품 A·B
└─ Box B ─ 송장 2 ─ 상품 C
```

## 정책

1. Box별 상품·수량과 송장번호를 함께 보존한다.
2. 하나의 Box에는 하나의 유효 송장만 연결한다.
3. 분할 포장에서는 모든 Box에 허용된 송장이 있어야 한다.
4. 송장 스캔 시 현재 패킹 중인 주문·Box와 일치하는지 확인한다.
5. Box 해체·재포장 시 기존 송장 관계를 무효화하거나 새 Box로 이전한다.
6. 상차 시 Box·송장 목록과 실제 화물을 대사한다.

## 예외

- Box 내용물과 송장 주문 불일치
- 한 Box에 여러 유효 송장
- 분할 Box 일부 송장 누락
- 재포장 뒤 기존 송장 관계 잔존
