# 배송지·주소 정제

<div class="page-meta"><span>배송·송장</span><span>주소 검증</span><span>9분</span></div>

주소 정제는 송장 발번 전에 송화인·수화인 주소와 우편번호를 택배사가 처리할 수 있는 형태로 검증·변환하는 단계다.

## 처리 흐름

<div class="flow-strip"><span>주문 배송지 조회</span><i>→</i><span>우편번호·기본·상세주소 검증</span><i>→</i><span>택배사 주소 정제 요청</span><i>→</i><span>도로명·지번·분류주소 저장</span><i>→</i><span>성공 시 송장 채번</span></div>

## 주소 정보

- 송화인·수화인 우편번호
- 도로명주소·상세주소
- 지번주소·상세주소
- 기타주소
- 택배 분류용 주소약칭
- 신주소·구주소 구분
- 주소 검증 결과코드·메시지

## 정책

1. 주소 검증과 송장 채번 결과를 별도 단계로 기록한다.
2. 주소 검증 결과코드가 성공이 아니면 정상 송장을 발번하지 않는다.
3. 정제 전 원본 주소와 정제 결과를 함께 보존한다.
4. 주문 배송지를 자동으로 덮어쓰지 않고 송장 발번에 사용한 주소 버전을 기록한다.
5. 주소 정제 실패 사유를 운영자가 확인할 수 있어야 한다.
6. 주소를 수정한 뒤에는 이전 실패 요청이 아니라 수정된 값으로 다시 검증한다.
7. 주소 검증 성공 후에도 송장번호가 없으면 발번 실패로 구분한다.

## 상태

| 결과 | 처리 |
|---|---|
| 주소 검증 성공 | 송장 채번 단계로 진행 |
| 주소 검증 실패 | 실패 코드·메시지 저장, 발번 차단 |
| 주소 성공·채번 실패 | 택배 주문·채번 오류로 분리 |

## 예외

- 우편번호·기본주소 누락
- 도로명·지번주소 해석 실패
- 주소 검증 결과코드 실패
- 정제 성공 후 송장번호 미반환
- 이전 주소로 재요청
- 복수 주문 중 일부 주소만 실패
