# 송장 발번

<div class="page-meta"><span>배송·송장</span><span>운송번호 생성</span><span>10분</span></div>

송장 발번은 택배사에 배송 정보를 전달하고 반환된 송장번호를 주문·Box에 연결하는 작업이다.

## 발번 흐름

<div class="flow-strip"><span>B2C 주문·Box 선택</span><i>→</i><span>택배사 선택</span><i>→</i><span>주소 검증·정제</span><i>→</i><span>택배 주문 접수</span><i>→</i><span>송장번호 채번</span><i>→</i><span>주문·Box 연결</span></div>

## 발번 결과

- 송장번호
- 택배사·배송 서비스
- 주문·출고번호
- Box 식별자
- 발번 요청·응답 시각
- 주소 검증 결과
- 택배 접수 결과

## 정책

1. B2C 송장 대상 주문에만 발번한다.
2. 주소 검증 성공 후 택배 주문·채번을 수행한다.
3. 반환된 송장번호가 없으면 발번 성공으로 처리하지 않는다.
4. 같은 요청을 재시도해도 중복 송장을 만들지 않게 한다.
5. 하나의 Box에는 하나의 유효 송장만 연결한다.
6. 송장번호, 주문·Box와 택배사 관계를 보존한다.
7. 발번 성공과 라벨 출력 성공을 별도로 기록한다.
8. 발번 실패 시 실패 단계·코드·메시지를 확인할 수 있어야 한다.

## 예외

- 주소 정제 실패
- 택배 주문 접수 실패
- 송장번호 미반환
- 같은 Box의 중복 발번
- 택배사 대역·계약 오류
- 발번 성공 후 응답 유실
