# 택배사·배송 방식

<div class="page-meta"><span>배송·송장</span><span>택배사 선택</span><span>8분</span></div>

택배사·배송 방식은 주문에 어떤 운송 서비스를 적용하고 어떤 방식으로 송장번호를 얻을지 결정한다.

## 배송 방식

| 방식 | 설명 |
|---|---|
| 택배사 연동 | CJ·한진 등 연동 API로 주소 검증·송장 발번 |
| 자체송장 | 운영자가 송장 정보·첨부파일을 등록 |
| 임시송장 | 실제 택배 송장과 구분되는 임시 출력물 |
| B2B 차량 출고 | 택배 송장 없이 차량·패킹 슬립·카톤 라벨로 처리 |

## 선택 조건

- 출고 유형 B2C·B2B
- 센터별 택배사 계약
- 화주별 택배사·서비스
- 배송지·권역
- 상품 특성·중량·Box
- 연동 사용 가능 상태

## 정책

1. B2C 송장 대상 주문만 택배사 송장 발번으로 보낸다.
2. B2B 차량 출고에는 택배 송장을 발행하지 않는다.
3. 센터·화주가 사용할 수 있는 택배사만 선택한다.
4. 택배사 변경 시 새 택배사의 주소·계약 조건을 다시 검증한다.
5. API 미연동 송장과 출력 가능한 연동 송장을 구분한다.
6. 선택한 택배사와 실제 발번된 송장의 택배사가 일치해야 한다.
7. 주문·Box별 택배사 변경 이력을 보존한다.

## 예외

- 사용 불가능한 택배사 선택
- 센터·화주 계약 없음
- B2B 주문의 택배 송장 발행 시도
- 택배사 변경 후 기존 송장 미무효화
- 자체송장과 연동 송장 중복
