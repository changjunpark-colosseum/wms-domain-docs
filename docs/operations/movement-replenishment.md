# 이동과 보충

<div class="page-meta"><span>재고 운영</span><span>작업</span><span>10분</span></div>

이동과 보충은 모두 재고 위치를 바꾸지만 목적이 다릅니다. **이동은 위치 변경 자체가 목적이고, 보충은 피킹 Location의 작업 가능 수량을 회복하는 것이 목적**입니다.

## 개념 비교

| 항목 | 이동 | 보충 |
|---|---|---|
| 시작 이유 | 재배치, 합치기, Zone 변경 | PICK Location 부족·예상 부족 |
| 출발지 | 허용된 모든 재고 Location | 주로 STORAGE·RESERVE |
| 도착지 | 정책상 허용된 Location | 주로 PICK |
| 수량 결정 | 작업자 지시 또는 요청 | Min·Max, 주문 수요, 용량 계산 |
| SOH | 유지 | 유지 |

## 공통 흐름

<div class="flow-strip"><span>작업 생성</span><i>→</i><span>출발지 확인</span><i>→</i><span>LPN·수량 확인</span><i>→</i><span>물리 이동</span><i>→</i><span>도착지 확인</span><i>→</i><span>원자적 반영</span></div>

## 보충 수량

```text
권장 보충량 = min(
  PICK 최대수량 - 현재수량,
  STORAGE 가용수량,
  예상 피킹수요
)
```

실제 시스템은 포장 단위, Location 용량, 우선 주문과 작업 마감시각도 함께 고려할 수 있습니다.

## 부분 이동

20 EA 중 6 EA만 옮기면 출발지 잔량 14 EA와 도착지 6 EA의 합이 이전 20 EA와 같아야 합니다. LPN을 분할한다면 부모·자식 계보를 남깁니다.

## 주요 정책

1. 출발지 감소와 도착지 증가는 하나의 원자적 작업입니다.
2. 이동 중 재고를 다른 작업이 동시에 사용할 수 없게 합니다.
3. 품질·LOT·유효기간과 소유자 속성을 보존합니다.
4. 대상 Location의 용도·용량·혼적 규칙을 검증합니다.
5. 취소·실패 시 실제 물리 위치를 기준으로 복구 경로를 결정합니다.

## 긴급 보충

피킹 도중 부족을 발견해 즉시 만드는 보충 작업입니다. 원래 피킹 작업과 보충 작업을 연결해야 하며, 보충 완료 전에 피킹 완료로 처리하지 않도록 상태 의존성을 관리합니다.

## 확인 문제

1. 이동 중 재고는 Available로 남아 있어도 될까요?
2. 보충 완료가 피킹 작업보다 늦게 도착할 때 어떤 상태 경쟁이 생길까요?
3. 출발지 감소 후 도착지 증가가 실패하면 어떤 보상 전략이 필요할까요?
