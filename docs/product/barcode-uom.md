# 바코드·UOM

<div class="page-meta"><span>상품</span><span>식별·수량 단위</span><span>9분</span></div>

바코드는 SKU를 스캔으로 찾는 식별자이고 UOM(Unit of Measure)은 수량을 표현하는 단위다. 바코드와 UOM은 재고 자체가 아니라 SKU의 취급 기준이다.

## 바코드

- 하나의 SKU가 여러 바코드를 가질 수 있다.
- 같은 테넌트 안에서 하나의 바코드가 여러 ACTIVE SKU를 가리키지 않게 한다.
- EA·INNER_BOX·BOX 등 포장 단위별 바코드를 등록할 수 있다.
- 입고 검수, 이동, 피킹과 패킹은 바코드로 SKU와 포장 단위를 확인한다.
- 바코드를 변경·폐기해도 과거 스캔 이력과 주문 참조는 보존한다.

## UOM

대표적인 단위는 다음과 같다.

| UOM | 의미 |
|---|---|
| EA | 낱개 기준 단위 |
| INNER_BOX | 내부 포장 단위 |
| BOX | 박스 포장 단위 |
| PLT | 팔레트 단위 |

```text
1 BOX = 12 EA
2 BOX 입고 = 24 EA
```

## 기준 단위

재고 장부는 하나의 기준 단위로 수량을 보존하고, 화면과 작업에서는 사용자가 입력한 UOM과 환산 수량을 함께 관리한다.

```text
입력 수량 × 환산계수 = 기준 단위 수량
```

## 정책

1. 입고·재고·출고·반품에서 같은 환산 기준을 사용한다.
2. 원래 입력한 수량·UOM과 환산 결과를 함께 보존한다.
3. 환산 결과는 재고 반영 전에 검증한다.
4. 포장 단위가 바뀌어도 이미 발생한 과거 수불 수량은 다시 계산하지 않는다.
5. 정수로 나누어지지 않는 포장 해체·재포장은 별도 작업 이력으로 관리한다.
6. 화면과 API에서 중복 환산하지 않는다.

## 예외

- 바코드가 여러 SKU에 중복 연결됨
- BOX 바코드를 EA로 잘못 인식함
- 입고와 출고의 환산계수가 다름
- 반품 수량을 두 번 환산함
- 포장 단위 변경 뒤 기존 재고와 신규 재고의 기준이 달라짐
